PELABUHAN SENJA — a coastal open-world crime game in the spirit of GTA 6, built
for the make.fun bounty gta6-01. Raka, a courier for the Lorong Senja crew, runs
five story missions through a neon-dusk port city: the Pasar Senja night market,
the harbor, the old town, and the Tanjung Api lighthouse. Drive sports cars,
outrun the police, and finish the last delivery.

All original work: procedural 3D city, vehicles, characters, terrain and sound —
no assets from any existing game. Runs fully offline in desktop Chrome.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move/drive, mouse to look, E to
enter/exit a car, Space to jump/handbrake, M for the city map, Esc to pause.
